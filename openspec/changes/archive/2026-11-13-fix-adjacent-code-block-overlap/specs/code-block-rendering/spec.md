# Spec Delta

## Purpose

定义博客文章正文中代码块的排版与交互规则，确保代码块之间、代码块与周围正文之间有稳定一致的垂直间距，同时保留语言标签、复制按钮与主题适配能力。

## ADDED Requirements

### Requirement: 相邻代码块之间保留垂直间距

文章正文中任意两个相邻的代码块（包括不同语言、无标题、以及 Mermaid 图表块）之间 SHALL 保留可见的垂直间距，任一代码块的上、下边缘都不得与相邻代码块的边缘紧贴或重叠。

#### Scenario: 连续两个代码块

- **WHEN** 文章的 Markdown 中两个代码围栏之间没有其他内容，页面渲染完成
- **THEN** 两个代码块之间出现与正文段落间距一致的可见空白，语言标签与圆角互不遮挡

#### Scenario: 代码块与正文段落相邻

- **WHEN** 代码块紧邻段落、列表或引用块
- **THEN** 代码块与其上下相邻元素之间同样保留可见的垂直间距

### Requirement: Mermaid 图表块保持相同间距规则

渲染为图表的 Mermaid 代码块 SHALL 与普通代码块遵循相同的垂直间距规则，图表替换源码块后间距不得消失。

#### Scenario: 相邻的 Mermaid 图表与代码块

- **WHEN** 文章的 Mermaid 代码块渲染为图表，且其相邻位置存在代码块
- **THEN** 图表与相邻代码块之间保留可见的垂直间距

### Requirement: 代码块既有视觉与交互保持不变

间距调整 SHALL NOT 改变代码块的其余呈现：圆角、语言标签内容与位置、复制按钮行为、浅色/深色主题配色、以及块内横向滚动。

#### Scenario: 间距修复后的代码块

- **WHEN** 用户浏览包含代码块的文章并切换浅色/深色主题
- **THEN** 语言标签仍显示在代码块左上角，复制按钮仍可用，超出宽度的代码行仍在块内横向滚动
